# Adaptive Traffic Signal Controller using AI
An AI-driven traffic management system designed to optimize signal timings based on real-time vehicle density.

## Overview
This repository contains the simulation and UI logic for an adaptive traffic controller. By analyzing simulated camera feed data (vehicle queue lengths), the system dynamically adjusts green light duration to reduce congestion. *Note: This project is the basis of an authored IEEE research paper.*
